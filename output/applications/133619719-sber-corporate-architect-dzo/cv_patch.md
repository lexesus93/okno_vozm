# Адаптация CV под Сбер — Корпоративный архитектор по работе с ДЗО (ДКА)

Вакансия: https://hh.ru/vacancy/133619719

## Базовый тип

**Основной:** `03-professional-it-consulting` — as-is/to-be, reference architecture, IT strategy, governance, enterprise delivery, работа с ЛПР и инициативами.

**Мостики:**
- `01-data-ai-platform-leader` — целевая архитектура, стандарты, многослойные ландшафты, Information Governance, архитектурная экспертиза проектов (Астра, IBM).
- `02-ai-data-business-adoption-partner` — AI-агенты, Cursor/on-prem LLM, генерация кода и автоматизация в рабочих процессах (явное требование вакансии).

**Не использовать как основу:** чистый `02` (слишком adoption), чистый `01` (слишком CDO/платформа данных без governance ДЗО).

## Что менять

1. **Заголовок:** «Руководитель IT-инициатив и корпоративной архитектуры» — leadership + связка с архитектурой, не «я архитектор».
2. **Профиль:** курирование, согласование, работа с архитектурными командами; явно не hands-on архитектор.
3. **Астра:** архитектурный отдел под руководством; не «выстраивал reference architecture»; не «встроил архитектурные процессы»; широкий портфель (Tivoli, Maximo, WebSphere, BPM + data/AI).
4. **Форсайт:** первый буллет — синхронизация + ЛПР + программы; без «архитектурно-инициативной экспертизы».
5. **IBM:** «организовывал», «руководил программами» — не «проектировал лично».
